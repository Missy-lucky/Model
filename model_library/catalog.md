# 虚拟模特分类

## eurasian-editorial

- 定位：欧亚混血感、高级店铺、成熟时装编辑感
- 适合：西装裤、牛仔裤、工装裤，以及腰带或金属配件明显的款式
- 当前试穿：1–8 号全部商品
- 正式人脸参考：`eurasian-editorial/face-reference-v4-natural.png`
- 最终成品目录：`../shop_model_800/eurasian/`

## korean-minimal

- 定位：韩系清透、年轻、简洁、轻盈通勤感
- 适合：针织衫、打底衫、基础上衣、简洁通勤装
- 当前试穿：1–8 号全部商品
- 正式人脸参考：`korean-minimal/face-reference-v3.png`
- 最终成品目录：`../shop_model_800/korean/`

## modern-chinese

- 定位：现代东方、沉静大气，强调垂坠感和结构
- 适合：阔腿裤、叠层裤、系带款，以及具有国风轮廓或面料质感的款式
- 当前试穿：1–8 号全部商品
- 正式人脸参考：`modern-chinese/face-reference-v3-natural.png`
- 最终成品目录：`../shop_model_800/modern-chinese/`

## 使用规则

- 商品图是服装结构、颜色、面料和细节的唯一依据。
- 模特参考图只用于身份、发型、体型、气质和摄影风格。
- 裤装搭配黑色或白色背心、吊带；上衣搭配低调纯色裤装。
- 保持全身入镜、自然重心，手部不遮挡商品关键结构。
- 未经确认的脸不进入正式身份参考。
- 最终店铺图统一为 `800×800` PNG；每位模特对每件商品各输出一张。
- 全身或裤装图采用自然的 7.5–8 头身比例、正常头部大小和 50mm 镜头透视，避免五五分或广角拉伸。
- 背景使用干净的浅灰或暖灰摄影棚墙面与地面，光线保持柔和自然，不使用硬棚灯、HDR 或油蜡感精修。
